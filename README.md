# KidiCraft Telegram Bot

## الملفات
- `index.js`: كود البوت.
- `package.json`: المكتبات وأمر التشغيل.
- `data.json`: يتم إنشاؤه تلقائيًا لحفظ الجروبات والرسائل والإعدادات.

## التشغيل
1. استخدم Node.js 18 أو أحدث.
2. ثبّت المكتبات:
   `npm install`
3. عيّن متغيري البيئة:
   - `BOT_TOKEN`: توكن البوت من BotFather.
   - `OWNER_ID`: رقم حساب تيليجرام الخاص بالمالك.
4. شغّل:
   `npm start`

لإظهار رقم حسابك، شغّل البوت مؤقتًا ثم أرسل `/id` في الخاص. ضع الرقم في `OWNER_ID` وأعد تشغيله.

## تسجيل جروب
1. أضف البوت للجروب.
2. من حساب المالك، اكتب `/addgroup` داخل الجروب.
3. أرسل `/mygroups` في الخاص للتأكد.

## ملاحظات مهمة
- لا ترفع توكن البوت إلى GitHub ولا ترسله لأحد. استخدم متغيرات البيئة في الاستضافة.
- إذا ظهر التوكن في صورة أو مستودع عام، ألغِه من BotFather وأنشئ توكنًا جديدًا.
- البوت ينشر نصوصًا فقط في هذا الإصدار.
- النشر يبدأ بعد مرور مدة الدورة المختارة، وليس فور الضغط على بدء.
- اترك البوت في الجروبات التي وافقت على النشر فقط.
