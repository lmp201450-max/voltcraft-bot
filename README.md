# بوت النشر التلقائي — LifeSteal

بوت تيليجرام بلوحة تحكم داخل الخاص. يدير الجروبات والمنشورات والردود التلقائية.

## المميزات

- نشر منشور محفوظ كل 5 دقائق بالتبادل بين المنشورات المفعلة.
- إضافة وتعديل وحذف المنشورات من لوحة التحكم.
- النص الطويل يُقسّم تلقائياً إلى رسائل لا تتجاوز حد تيليجرام للرسالة الواحدة.
- تسجيل الجروبات وإزالتها من لوحة التحكم.
- إضافة وتعديل وحذف ردود الكلمات المفتاحية.
- الردود التلقائية تعمل في الخاص فقط.
- زر مستقل لتشغيل وإيقاف النشر، وزر آخر للردود.
- يضيف تلقائياً رد كلمة الجروب ورابط https://t.me/Lifestyle1589 عند أول تشغيل لقاعدة البيانات.
- يحفظ البيانات في PostgreSQL حتى لا تضيع عند إعادة تشغيل الخدمة.

## الملفات

- index.js — تشغيل البوت واللوحة والنشر والردود.
- database.js — اتصال PostgreSQL وإنشاء الجداول.
- package.json — المكتبات وأوامر التشغيل.
- .env.example — أسماء متغيرات البيئة المطلوبة.
- render.yaml — إعداد خدمة Render.

## قبل التشغيل

1. أنشئ بوتاً من @BotFather وخذ التوكن.
2. أنشئ قاعدة بيانات PostgreSQL واحصل على رابط الاتصال DATABASE_URL.
3. احصل على رقم حسابك في تيليجرام.
4. أضف البوت إلى الجروبات كمشرف مع صلاحية إرسال الرسائل.

## التشغيل محلياً

1. انسخ .env.example إلى ملف اسمه .env.
2. املأ BOT_TOKEN وADMIN_IDS وDATABASE_URL في .env.
3. نفّذ:

npm install
npm start

## الرفع إلى GitHub وRender

1. أنشئ مستودع GitHub جديداً وارفع ملفات المشروع كلها.
2. في Render اختر New > Web Service واربط مستودع GitHub.
3. Build Command: npm install
4. Start Command: npm start
5. أضف متغيرات البيئة في Render:
   - BOT_TOKEN
   - ADMIN_IDS
   - DATABASE_URL
   - WEBHOOK_SECRET
   - NODE_ENV = production

## إضافة الجروبات

1. أضف البوت إلى الجروب كمشرف.
2. أرسل /register داخل الجروب من حساب المدير.
3. افتح البوت في الخاص وأرسل /start.
4. لإزالة الجروب أرسل /unregister من داخله أو احذفه من اللوحة.

## ملاحظات

- يجب أن يكون البوت مشرفاً وقادراً على إرسال الرسائل.
- البوت لا يضيف نفسه إلى الجروبات؛ أضفه أنت أولاً.
- خدمة Render المجانية قد تدخل في وضع السكون؛ لذلك لا يكون النشر كل 5 دقائق مضموناً أثناء توقف الخدمة.
- لا ترفع ملف .env إلى GitHub.
